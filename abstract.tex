\chapter*{Abstract}

Precision agriculture relies on accurate, large-scale crop mapping derived from Earth Observation data, particularly Satellite Image Time Series (SITS).
However, operationalizing deep learning for SITS presents severe challenges.
First, tracking high-dimensional spatial-temporal grids creates critical memory bottlenecks in High-Performance Computing (HPC) environments.
Second, most state-of-the-art models suffer from "temporal myopia"; they analyze single-year phenology while completely
ignoring the fundamental agronomic practice of multi-year crop rotation. 

This thesis bridges these gaps by proposing a scalable machine learning framework designed to efficiently capture both intra-year phenology and inter-year crop dynamics.
To solve hardware limitations, the data pipeline is transitioned to an optimized 1D pixel-based extraction method, enabling rapid,
large-scale processing of a six-year Sentinel-2 dataset over Austria (INVEKOS). 

The research systematically establishes robust single-year baselines, directly comparing a 1-Dimensional
Convolutional Neural Network (1D-CNN) against standalone Transformer Encoders.
Furthermore, structural control tests utilizing a simplified linear backbone are executed to definitively prove the
mathematical necessity of non-linear feature extractors when processing raw SITS.
To model long-term agricultural dynamics, these feature extractors are integrated into two distinct multi-year architectures:
the established Transformer-HMM Bayesian cascade---which smooths temporal predictions using explicit,
fixed transition matrices---and a novel Hierarchical Transformer-LSTM. 

Experimental results demonstrate that multi-year architectures vastly outperform traditional single-year phenological models.
Crucially, the novel Transformer-LSTM proves that deep recurrent memory can intrinsically learn complex,
non-linear multi-year crop rotation rules end-to-end without relying on predefined agronomic matrices,
achieving classification performance competitive with the state-of-the-art HMM cascade.
By delivering this optimized, automated MLOps framework, this thesis provides both a highly scalable software
solution for crop mapping and critical insights into the capacity of deep neural networks to decode long-term agricultural history.
